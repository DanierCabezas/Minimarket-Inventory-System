# Minimarket Inventory System

## Descripción

Proyecto práctico de aprendizaje desarrollado con Python y SQLite, cuyo objetivo es crear un sistema de registro y gestión de productos para un supermercado.

Este proyecto permite aplicar conocimientos básicos de programación, lógica computacional y manejo de bases de datos relacionales.

## Funcionalidades

- Registrar productos.
- Mostrar todos los productos registrados.
- Buscar productos por código.
- Modificar información de productos.
- Eliminar productos.
- Buscar productos por categoría.
- Identificar productos agotados.
- Calcular el total de productos y el valor del inventario.

## Tecnologías utilizadas

- **Python:** lenguaje utilizado para desarrollar la lógica del programa.
- **SQLite:** sistema de gestión de bases de datos utilizado para almacenar y consultar la información.

## Estructura del proyecto

- `menu.py`: contiene las funciones y el menú principal del sistema.
- `dato_registros.db`: base de datos SQLite utilizada por el proyecto.

## Ejecución

1. Clonar el repositorio:

   ```bash
   git clone https://github.com/DanierCabezas/Minimarket-Inventory-System.git
   ```

2. Entrar en la carpeta:

   ```bash
   cd Minimarket-Inventory-System
   ```

3. Ejecutar el programa:

   ```bash
   python menu.py
   ```

## Aprendizajes

Durante el desarrollo de este proyecto practiqué:

- Variables, funciones y estructuras de control en Python.
- Manejo de entradas de usuario.
- Conexión de Python con SQLite.
- Operaciones CRUD (crear, consultar, actualizar y eliminar registros).
- Consultas SQL utilizando SELECT, INSERT, UPDATE y DELETE.
- Uso de Git y GitHub para el control de versiones.
